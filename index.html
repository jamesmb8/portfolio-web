Allergy Scanner App

FlutterDartFirebase (Auth, Firestore, Storage, FCM)OCRCamera AccessContact Access

Overview

The Allergy Scanner App helps users quickly identify allergens in food products by scanning ingredient lists. It’s built in Flutter with Firebase for real-time data, authentication, and notifications. Designed to look and feel like a modern iOS app, the interface uses clean typography, soft shadows, and gesture-based navigation for an Apple-like experience.

  • OCR for ingredient list scanning
  • Personal scan history with quick sharing
  • Voice search and notification reminders for allergens
  • Secure Firebase Authentication and Firestore integration

The app has been tested through TestFlight and is now available on the App Store for iPhone users.

Kerridge Optimisation App

Data visualisationClient collaborationPerformance zonesAlgorithm Design

Overview

Developed a desktop optimisation tool for Kerridge Commercial Systems (KCS) that visualises and categorises vehicle loading efficiency. The app allows users to view package layouts across multiple layers, identify underutilised space, and optimise vehicle loading performance.

  • Built in C# (WPF) with an interactive, layered 2D lorry visualisation
  • Implemented rule-based stacking logic considering weight and height constraints
  • Enabled dynamic layer selection and detailed package breakdowns
  • Collaborated directly with KCS engineers to refine requirements and usability

The solution provided clear, visual insights into loading efficiency — improving decision-making for logistics planning and warehouse operations.

Travel Optimisation (Upcoming)

Flutter Dart Google Maps API TransportAPI REST APIs Data Visualisation Sustainability

Overview

The Travel Optimisation App will help users find the fastest, cheapest, and most sustainable way to travel to any destination. It integrates live transport data from Google Maps and TransportAPI to compare multiple travel modes — including driving, public transport, and walking — while estimating CO₂ emissions for environmental awareness.

  • Built with Flutter using real-time REST APIs for live transport data
  • Displays side-by-side route comparisons with time, cost, and CO₂ metrics
  • Uses Google Maps Directions API for route mapping and distance calculations
  • Integrates TransportAPI for UK-based public transport times and fares
  • Features a clean, modern UI inspired by Apple’s travel and maps apps

Designed as part of my final-year project at Sheffield Hallam University, this app focuses on improving travel efficiency and sustainability awareness for everyday commuters.
